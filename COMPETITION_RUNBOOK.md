# TambaQu Competition Runbook

## Before Presentation

1. Charge the laptop and disable battery-saving restrictions.
2. Open the production TambaQu URL while internet is available.
3. Enter Mode Demo and confirm `Tambak Mina Jaya` with four ponds.
4. Open Kontrol Demo and choose **Reset Demo**.
5. Confirm Kolam B starts at Risk Score 22.
6. Run the Warning scenario once and confirm PondBrain opens.
7. Reset again so the audience sees the clean baseline.
8. Keep one backup browser tab open on Dashboard.
9. Avoid clearing site data after the offline cache has been prepared.

## 90-Second Golden Demo

1. Show Dashboard and the four ponds at Tambak Mina Jaya.
2. Open Kontrol Demo, select Warning, and start it for Kolam B.
3. Show DO decreasing, amonia increasing, and Risk Score moving 22 → 34 → 48 → 58 → 67.
4. Open PondBrain and show contributors: DO 42%, Amonia 27%, Suhu 18%, and Konteks Lingkungan 13%.
5. Open the primary recommendation and choose **Tandai Sudah Dilakukan**.
6. Enter `Aerator tambahan diaktifkan.` and save.
7. Show the Action Timeline update.
8. Return to Dashboard and show the latest action.

## 45-Second Offline Demo

1. Reset, advance Kolam B to Waspada, then switch Simulasi Koneksi Aplikasi to **Offline**.
2. Point out the offline banner and that cached monitoring remains visible.
3. Open PondBrain, record an action, and show **Menunggu sinkronisasi**.
4. Restore **Online**.
5. Show **Menyinkronkan**, then **Tersinkron**.
6. Clarify that app connectivity and sensor-device connectivity are separate states.

## If Internet Fails

1. Stay in the already installed/cached TambaQu tab.
2. Explain the offline-first behavior while continuing with cached data.
3. Record the action offline and show pending synchronization.
4. Do not clear browser data or close the final cached tab.

## If Simulator Fails

1. Open Kontrol Demo and choose **Reset Demo**.
2. Select Warning and use **Langkah Berikutnya** if timed playback is unsuitable.
3. If it still fails, show the fixed Kolam B warning state from the prepared backup tab.

## If PondBrain Fails

1. Continue with Pond Detail.
2. Show the sensor trend, Risk Score, device freshness, and active warning.
3. Explain the recommended operational check verbally; one module must not end the presentation.

## After Rehearsal

1. Restore simulated connection to **Ikuti Browser**.
2. Reset Demo.
3. Confirm no pending synchronization remains.
4. Leave Dashboard open at the baseline state.

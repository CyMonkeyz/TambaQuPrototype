# TambaQu Competition Demo Script

## 90-second demo

1. In Settings, choose **Reset Data Demo**, then open **Demo Control**.
2. Select **Warning Escalation**. Kolam B begins at Risk 22 / Aman, DO 5.8, and ammonia 0.03.
3. Choose **Start** or use **Next Step** for presenter-controlled timing.
4. Return to Dashboard. Show DO declining and Risk 22 → 34 → 48 while one early-warning alert appears.
5. Continue to Risk 67 / Waspada. Open PondBrain for Kolam B.
6. Show contributors: DO 42%, Amonia 27%, Suhu 18%, and Context 13%.
7. Complete **Periksa dan optimalkan aerasi** with note `Aerator tambahan diaktifkan.`
8. Show the action timeline, Dashboard recent activity, and Reports action count.
9. Emphasize that monitoring continues; the prototype does not claim a biological outcome.

## Critical scenario

1. Reset, select **Critical**, and step through Risk 67 → 76 → 84.
2. Show the unique critical alert, dashboard priority, and immediate PondBrain inspection recommendation.
3. Record an action, then select **Recovery** without resetting.
4. Show Risk 84 → 76 → 61 → 48 and the wording **indikator risiko menurun**.

## Device failure scenario

1. Select **Device Failure** and step Online → Degraded → Offline.
2. Show that historical data remains visible and PondBrain labels data as limited.
3. Advance once more to restore the simulated sensor connection.
4. Explain that sensor-device connectivity differs from farmer-app internet connectivity.

## Presenter safeguards

- Use **Next Step** when timing must be exact.
- Use Presentation Mode for a larger command-center surface.
- Reset is deterministic and clears scenario alerts, actions, and the demo outbox.
- All content is synthetic demo data.
